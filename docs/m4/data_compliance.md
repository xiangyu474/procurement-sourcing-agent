# 数据合规说明

本文说明系统处理哪些数据、数据存储在哪里、哪些数据彼此隔离，以及当前实现的合规边界。面向评委、评审和交付后的运维人员。

## 1. 数据来源与存储

| 数据 | 来源 | 存储位置 |
| --- | --- | --- |
| 需求文字 | 访客输入 | 文本和修订元数据存 D1，并受访客会话归属保护。 |
| PPTX 需求文件 | 访客上传 | 原文件存私有 R2，来源元数据存 D1。 |
| 历史 XLSX | 访客上传，可选 | 原文件和标准化 JSON 存私有 R2，数据集元数据存 D1。 |
| 公开网页正文 | Tavily Extract | 文本或 Markdown 快照存私有 R2。URL、时间、哈希和定位存 D1。 |
| 技术声明 | 模型从网页快照中提取 | 声明、逐字引文和 Evidence ID 存 D1。 |
| 核验与采购建议 | 确定性计算器和决策门禁 | 结果存 D1，冻结快照存 D1。 |
| DOCX 报告 | `python-docx` 模板 | 文件存私有 R2，状态和 SHA-256 存 D1。 |
| 模型与工具轨迹 | 模型调用、Tavily 调用和子任务 | LangSmith 保存原始轨迹。 |
| 搜索摘要 | Tavily Search | 只用于发现来源，不作为证据保存。 |

系统不保存网页原始 HTML 或 PDF 二进制镜像。用户上传的 PPTX 和 XLSX 原文件按上传对象保存。

## 2. 浏览器保存的数据

浏览器不保存模型密钥、检索密钥、内部令牌或运维 Bearer。访客身份由一枚 `__Host-ps_session` HttpOnly Cookie 表示。该 Cookie 有效期为 24 小时，不能被前端脚本读取。

前端本地存储包含：

- 最近项目的 ID、标题、运行 ID 和页面状态。
- 最近一次提交的需求文字，用于页面恢复。
- 当前项目尚未提交的输入草稿。

这些本地数据不等同于服务端项目归属。清空浏览器数据不会删除 D1 或 R2 中的项目。

## 3. 外部服务收到的数据

| 服务 | 接收内容 | 不接收内容 |
| --- | --- | --- |
| OpenAI 兼容模型接口 | 当前任务需要的需求片段、来源片段、结构化上下文。 | 访客 Cookie、Bearer 凭证、密钥、其他访客项目。 |
| Tavily Search | 从公开市场信息改写后的研究问题。 | 访客 Cookie、内部供应商名称、订单号、数量、计划价格和项目秘密。 |
| Tavily Extract | 已由当前研究任务发现的公开 URL。 | 私有 URL、访客凭证和未列入当前任务的网址。 |

模型调用和检索都使用服务端密钥。密钥不进入浏览器、Git、报告或业务数据库。

## 4. 访客隔离

访客会话是资源归属边界。项目、运行、分析、证据、报告和下载都绑定 `session_id`。

- 访客 A 读取访客 B 的资源时返回 404。
- 404 同时覆盖资源不存在和资源属于其他访客，避免泄露资源存在性。
- 过期 Cookie 不能恢复旧项目访问权。
- 没有 `session_id` 的历史项目不向公开访客开放。

云端验收已覆盖两个真实访客之间的项目、运行、分析、报告和下载隔离。

## 5. 限流与预算

| 控制 | 当前配置 |
| --- | --- |
| 新会话 | 全局每小时 60 次，每 IP 每小时 10 次 |
| 已认证请求 | 全局每分钟 600 次，每会话每分钟 120 次 |
| 任务并发 | 全局 2 个，每访客 1 个 |
| 访客日额度 | 16 个预算单位，最多 6 次启动 |
| 全局日额度 | 80 个预算单位 |

预算单位限制并发和日量。它不是模型调用次数，也不是金额。寻源阶段另有搜索、抓取、任务、轮次和模型调用上限。

IP 只保存 HMAC，不保存原始地址。IP 只作为滥用信号，不作为身份。同一区域的 Worker 子请求可能改写地址，因此不能依赖 IP 做精确归属。

## 6. 模拟历史与公开企业

官方素材中的历史采购记录属于模拟数据。系统使用独立命名空间保存这些主体。

- 模拟供应商不会自动映射到现实企业。
- 系统不按供应商名称连接历史与公网数据。
- 历史与公网数据只按已确认的产品等价关系融合。
- 没有确认关系的同名记录保持分离。

页面和报告会标注历史数据为模拟数据。

## 7. 结论与证据约束

- 技术结论只使用抓取后的来源正文。模型记忆和搜索摘要不能支持技术结论。
- 声明值必须出现在逐字引文中，否则声明保持未核实状态。
- 语义不一致、单位无法换算或来源冲突时，结论为 `UNKNOWN`。
- 硬约束 `FAIL` 的型号不能进入询价短名单。
- 价格按口径分组。不可比的价格不产生最低价或节支率。
- 原始英文理由没有逐条翻译时，页面显示结构化中文摘要，并说明仍有原文待核对。

网页和 DOCX 读取同一 `decision_version`。后续供应商情报更新不会改写旧报告。

## 8. 报告中的数据

正式 DOCX 包含：

- 需求摘要、硬约束和原文引用。
- 候选、型号、技术结论、采购建议和 Evidence ID。
- 逐约束判定、计算式和原因码。
- 历史范围、统计口径和价格可比性。
- 未解决问题和下一步。
- 来源 URL、逐字摘录和内容哈希。

报告不包含模型密钥、访客凭证、内部存储路径或原始异常堆栈。

## 9. 当前边界

- 没有逐次模型调用计费。预算单位不是费用上限。
- 没有自动数据过期或用户自助删除接口。项目、证据和报告的保留周期需要运维或合规负责人制定。
- 模型语义对齐仍有误判风险。代码会校验引文、同义表、单位和门禁，但不能证明任意自然语言都理解正确。
- 供应商身份默认是 `DISCOVERED_UNVERIFIED`。系统不声称完成工商、司法、海关或产能核验。
- LangSmith 保存模型和工具轨迹。部署方应按实际使用环境配置追踪保留期限和访问权限。
